# AIIRK — экосистема ИИ-агентов

Неоновая фирменная версия интерактивного сайта AIIRK для демонстрации архитектуры ИИ-агентов.

## Ветка

Эта ветка содержит вторую версию сайта в фирменном стиле AIIRK:

- тёмно-синяя палитра;
- холодное неоновое свечение;
- стеклянные интерфейсные панели;
- интерактивная карта модулей;
- сценарии запуска лендинга, контент-системы и автоматизации;
- адаптивная вёрстка.

Первая версия сайта сохранена в ветке `main`.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

## Производственная сборка

```bash
npm run build
npm run start
```
